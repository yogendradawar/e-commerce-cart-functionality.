# E-Commerce Cart Functionality 🛒

A comprehensive e-commerce platform specializing in cutting-edge tech gadgets. Features a fully functional shopping cart, product catalog, and seamless user experience for online shopping.

## 🌟 Features

### 🛍️ **Shopping Experience**
- Interactive product catalog with detailed descriptions
- Advanced shopping cart functionality
- Real-time price calculations
- Stock availability tracking
- Quantity management for cart items
- Tax calculation and final total display

### 📱 **Product Categories**
- **Computers**: Laptops with detailed specifications
- **Mobiles**: Feature-rich smartphones
- **Audio**: Wireless headphones and speakers
- **Wearables**: Smartwatches and fitness trackers
- **Video**: Smart televisions and displays

### 💰 **Pricing & Offers**
- Dynamic pricing with discounts
- New Year Sale: Extra 50% off on selected items
- Real-time total calculations
- Tax integration
- Special promotional banners

### 🚚 **Customer Services**
- Worldwide shipping for orders above $100
- Easy 30-day returns policy
- Money-back guarantee within 30 days
- 24/7 online customer support

## 🛠️ Built With

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Responsive Design**: Mobile-first approach
- **Cart Management**: Local storage for cart persistence
- **Dynamic Content**: Real-time price and quantity updates
- **Deployment**: Netlify with continuous deployment
